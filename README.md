# DEVA Creative Portfolio

A static, responsive portfolio website built with HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

## Deploy on Vercel

1. Extract this ZIP file.
2. Create a new GitHub repository.
3. Upload **the files inside this folder** to the repository root. Make sure `index.html` is at the top level, not inside another nested folder.
4. On Vercel, choose **Add New → Project**, import that GitHub repository, and click **Deploy**.
5. Since this is a static HTML website, leave the framework preset as **Other** (or use the static site option if offered). No build command is needed, and the output directory can be left blank/default.
6. After deployment, click **Visit**.

## Run locally

Open `index.html` in a browser, or use VS Code's Live Server extension.

## Before sharing your live website

Open `index.html` and replace any placeholder contact information and social links with your real details.

- The contact form opens the visitor's default email application. It does not send messages to a server.
- The portfolio's Admin Mode stores uploaded videos only in that browser's local IndexedDB. Those videos are not uploaded to Vercel and are not visible to other visitors.
- The CV button downloads a starter text CV, not a professionally formatted PDF.
- Sample project cards are illustrative examples. Replace their titles and descriptions with your actual work.
